One short funny line answering a prompt: the excuse a robot vacuum gives
after eating a sock. The vacuum defends itself like a lawyer quoting its
own job description — the sock was on the floor, the job says "floor", so
it did nothing wrong. Deadpan, tight, and the joke comes from the machine
reading its instructions literally.

> My job description says 'floor.' The sock was on the floor. I rest my case.

## Run it

```sh
node main.ts
```

That writes `/output/entry.txt` — one line, 75 characters, inside the
1–200 character gate. The program validates the line against the gate
before writing and verifies the round trip after writing.
